# FarmConnect AI — API Reference for Frontend

Base URL (local): `http://localhost:8787`  
Base URL (production): `https://farmconnect-ai-worker.<your-subdomain>.workers.dev`

Set `NEXT_PUBLIC_WORKER_URL` in `my-app/.env.local` to point to the correct base URL.

---

## Suggested frontend utility

```ts
// src/lib/api.ts
const BASE = process.env.NEXT_PUBLIC_WORKER_URL ?? 'http://localhost:8787'

async function apiFetch<T>(
  path: string,
  options?: RequestInit
): Promise<T> {
  const res = await fetch(`${BASE}${path}`, {
    headers: { 'Content-Type': 'application/json' },
    ...options,
  })
  const data = await res.json() as { success: boolean; data?: T; error?: string }
  if (!data.success) throw new Error(data.error ?? 'API error')
  return data.data as T
}

export const farmApi = {
  health: () => apiFetch('/api/health'),
  ai: (task: string, context: object) =>
    apiFetch('/api/ai', { method: 'POST', body: JSON.stringify({ task, context }) }),
  weather: (location: string) =>
    apiFetch(`/api/weather?location=${encodeURIComponent(location)}`),
  weatherAdvice: (body: object) =>
    apiFetch('/api/weather/advice', { method: 'POST', body: JSON.stringify(body) }),
  cropRecommend: (body: object) =>
    apiFetch('/api/crops/recommend', { method: 'POST', body: JSON.stringify(body) }),
  farmerMatch: (body: object) =>
    apiFetch('/api/farmers/match', { method: 'POST', body: JSON.stringify(body) }),
  laborNearby: (lat: number, lng: number, radius = 5, skill?: string) =>
    apiFetch(`/api/labor/nearby?lat=${lat}&lng=${lng}&radius=${radius}${skill ? `&skill=${skill}` : ''}`),
  laborRequest: (body: object) =>
    apiFetch('/api/labor/request', { method: 'POST', body: JSON.stringify(body) }),
  marketplace: (filters?: Record<string, string>) =>
    apiFetch(`/api/marketplace?${new URLSearchParams(filters).toString()}`),
}
```

### `POST /api/ai`
General AI advisor. Supports 7 task types.

**Tasks:** `crop_recommendation` · `weather_action` · `crop_diagnosis` · `fertilizer_advice` · `livestock_advice` · `farm_plan` · `profit_analysis`

```bash
curl -X POST http://localhost:8787/api/ai \
  -H "Content-Type: application/json" \
  -d '{
    "task": "crop_diagnosis",
    "context": {
      "crop": "rice",
      "location": "Tamil Nadu",
      "symptoms": "yellow leaves, stunted growth",
      "growthStage": "tillering"
    }
  }'
```
```json
{
  "success": true,
  "data": {
    "task": "crop_diagnosis",
    "recommendation": "Likely nitrogen deficiency or brown planthopper infestation...",
    "sections": [
      { "title": "Probable Cause", "content": "...", "priority": "high" },
      { "title": "Recommended Treatment", "content": "...", "priority": "high" },
      { "title": "Prevention", "content": "...", "priority": "medium" }
    ],
    "safetyNote": "This advice is generated by an AI system for informational purposes only..."
  }
}
```

## Error Response Shape

All errors follow the same shape:
```json
{
  "success": false,
  "error": "Human-readable message",
  "code": "MACHINE_READABLE_CODE"
}
```

| HTTP | Code | Meaning |
|------|------|---------|
| 400 | `MISSING_FIELD` / `INVALID_VALUE` / `INVALID_JSON` | Bad request from client |
| 404 | `NOT_FOUND` | Route does not exist |
| 503 | `AI_ERROR` | Gemini temporarily unavailable |
| 500 | `INTERNAL_ERROR` | Unhandled server error |
